# Поиск фильмов

Учебное React-приложение для поиска фильмов и просмотра информации о них. Проект создавался в рамках обучения при поддержке наставника.

## Возможности

- поиск фильмов по названию;
- просмотр списка результатов и страницы фильма;
- добавление фильмов в избранное и удаление из него;
- сохранение избранного в `localStorage`;
- заглушка, если постер фильма недоступен.

## Технологии

- React;
- React Router;
- JavaScript;
- CSS;
- Fetch API;
- `localStorage`;
- Kinopoisk Unofficial API.
